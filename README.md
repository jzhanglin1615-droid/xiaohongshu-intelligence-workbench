# 小红书内容情报台

本地优先的候选采集与趋势分析工具。它帮助使用者从自己能访问的页面中整理选题和帖子，观察已采集样本的变化；它**不是**小红书官方产品，也不提供全站完整数据。

> 状态：早期预览。仓库包含可运行源码和离线测试，但尚无跨设备安装验收，也没有经过持续真实平台采集的可靠性证明。界面或页面结构变化可能影响采集。

## 已知边界

- 读取用户浏览器中可见的页面，不绕过登录、验证或访问限制。遇到验证或页面结构不认识时应停止并报告。
- 榜单只代表本机已采集样本，不代表小红书全站完整数据；缺失的点赞、收藏、转发不是零。
- 目前没有完成跨设备安装验收，也没有可证明稳定运行的真实平台完整采集样本。不要把本地测试通过当成实际平台可靠性保证。
- 作品和账号改进建议是分析辅助，不保证增长。使用者应自行遵守平台规则并评估自己的使用权限。
- 模型 API 默认关闭。启用后才会请求配置的模型服务；请勿提交 API Key。

## 本地运行（Windows）

需要 Node.js 24 或更新版本、PowerShell、Chrome 或 Edge。无需 `npm install` 即可运行当前源码。

```powershell
node --version
npm run setup
npm test
npm run ui
```

然后访问 `http://127.0.0.1:4173/`。`npm run ui` 会自动补齐缺失的本地空白状态文件，**不会覆盖**已有状态。初始榜单为空，不包含任何真实采集记录。若要验证离线示例流程，可运行 `npm run demo:intelligence`；这会在本地 `artifacts/` 写入**虚构夹具**结果，切勿当作平台数据。

Windows 也可双击 `启动采集台.cmd`，并使用同目录的停止、状态查看入口；这些入口共用同一套本地服务控制逻辑。

浏览器扩展位于 `apps/browser-extension`，可在扩展管理页用“加载已解压的扩展程序”本地安装。扩展只连接本机 `127.0.0.1:4173` 与小红书页面。请先阅读代码、了解采集范围，再自行决定是否启用；本预览没有代用户执行平台操作。

## 隐私和数据

真实采集、数据库、运行日志、方向设置和加密模型配置写入 `state/`；生成的离线报告在 `artifacts/`。两者均被 Git 忽略。首次运行的空白模板在 `templates/bootstrap/`。公开仓库不应收录真实运行数据，也不应收录个人截图、媒体、Cookie、链接令牌或 API Key。

`config/model-providers.json` 只提供服务商地址样例和路由，不含用户密钥。使用者如修改它，应在提交前自行检查。

## 安全与贡献

工作台仅监听 `127.0.0.1`，但同一电脑上的其他进程可能访问本地端口。请勿将其转发到公网或不可信网络。浏览器扩展会向本地服务发送跨源请求，使用前请审查权限。
